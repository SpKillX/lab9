Вариант: 1

Стек: Python 3.13, Go, Rust (PyO3)

📋 Обзор заданий
Средний уровень (Medium)
Задание 1 (Go HTTP-сервер): Реализован HTTP-сервер на Go, возвращающий приветственное сообщение.

Задание 3 (Go Subprocess): Python-скрипт запускает скомпилированный Go-бинарник calculator.exe, который вычисляет сумму чисел от 1 до 10. Результат: 55.

Задание 6 (Rust Library): Создана библиотека на Rust для базовых арифметических операций, интегрированная в Python.

Повышенный уровень (High)
Задание 1 (Go Microservice): Микросервис на Go для выполнения математических вычислений, доступный по HTTP.

Задание 4 (Orchestration): Python выступает в роли оркестратора. Он запрашивает данные у Go-микросервиса и передает их в Rust-библиотеку для обработки (имитация шифрования).
